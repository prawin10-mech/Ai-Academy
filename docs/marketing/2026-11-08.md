**LinkedIn** (under 1200 characters)

A test that passes once is not a passing test. Every web developer knows this from flaky tests, and it applies even more to AI features.

A dev digest reported on Nov 7 that Google's Agent Development Kit 2.14.0 added multi-run evaluation, so the same test can be repeated several times. I have not tried it, and the details come from the digest's summary.

The idea works with any stack, even without that tool:

1. Write 15 questions with the answers you expect.
2. Run each one 3 times, not once.
3. Mark a task as passing only if it passes every time.
4. Save the failures and rerun them after each prompt or model change.

If a task passes 2 out of 3 times, that is a bug you can show a user, not a lucky run.
