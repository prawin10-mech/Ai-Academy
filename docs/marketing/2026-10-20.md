**LinkedIn** (about 1000 characters)

Web search just became a line item on your agent's bill.

DeepSeek now lists Search and Fetch APIs at $0.75 per 1,000 successful requests. Calls made through some coding agents are free for a while, and then they are not.

If you build with agents, this is a normal API-cost problem, and web developers already know how to handle it:

1. Set a maximum number of searches per task. Stop the loop when you hit it.
2. Cache results. The same question should not pay twice.
3. Log every call with the query and the cost, so you can see where money goes.
4. Test with a small set of saved questions before you ship, so a change does not quietly double your calls.

A "smart" agent that can search is also an agent that can search 40 times for one answer. The limit is your job, not the model's.
