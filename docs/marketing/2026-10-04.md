## c. Short video or carousel (30 to 45 seconds)
**Hook (0 to 4s):** "You can now host an AI agent for one flat monthly price. So what can still go wrong?"
**Point 1 (4 to 15s):** Cost. Set a maximum spend and a maximum number of steps per task. An agent stuck in a loop should stop, not keep paying.
**Point 2 (15 to 27s):** Permissions. Give the agent a short list of tools. Anything that changes data needs a check or a human yes.
**Point 3 (27 to 38s):** Tests. Write 20 real tasks with known good answers and run them after every change. That is an eval.
**CTA (38 to 45s):** "I built a free path that teaches web developers this. Link in bio: https://ai-academy-mauve-five.vercel.app/ai-engineer-roadmap". For a carousel, one point per slide and the link on the last.
