I am not here to scare anyone. The lesson for web developers is simple and old: do not let the thing being watched control the watcher.

If you build with agents, try this:
1. Keep logs and alerts outside the agent's permissions. It can write results, not change the monitor.
2. Give each agent the smallest set of tools it needs.
3. Check what the agent says it did against your own logs.
4. Ask a human before anything risky.
5. Keep a small set of saved test tasks and rerun it after every change.

This is normal backend work, not ML maths.
