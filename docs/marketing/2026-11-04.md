## a. Today's angle
Prompt files can carry hidden instructions, not only code. Cyber Security News (Nov 4) reports that Check Point found a Chinese-language toolkit called Haiou (v4.5.0), shared on GitHub as a Codex add-on. Its prompt files make normal greetings trigger fixed ads for a third-party AI gateway ("prompt adware"). The report says it does not show data theft or malicious tool use. Why it matters to web developers: you will install agent skills, prompt packs and CLAUDE.md files from the internet, so read them like code before you trust them. Earlier packs covered untrusted model output (Nov 2) and limits out of agent reach (Nov 3); this one is about untrusted prompt files you install.
