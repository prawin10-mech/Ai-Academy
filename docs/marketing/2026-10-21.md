**LinkedIn** (about 1000 characters)

Your AI agent can now run for a whole day. Who stops it if it goes wrong?

Notion is reported to have rebuilt its agent system so a single task can run for over 24 hours, up from about five minutes. I have not confirmed the details on Notion's own pages, but the direction is clear: agents are moving from quick answers to long background jobs.

Web developers already know how to run long jobs. The same rules apply:

1. Set a budget. A maximum cost and a maximum number of steps per task.
2. Save progress. If it crashes at hour 9, it should resume, not restart.
3. Log every step, so you can see what it did and why.
4. Add a stop button and a human approval step before anything risky.
5. Test on a small saved set of tasks before you let it run overnight.

None of this needs ML maths. It is normal backend work around a model.
