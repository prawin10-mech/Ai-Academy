## c. Short video or carousel (30 to 45 seconds)
**Hook (0 to 4s):** "Bots with AI brains sent 200,000 requests to one government database this year. Is your API ready?"
**Point 1 (4 to 15s):** Rate limit every route, by user and by IP. Return a clear 429 so well-behaved agents back off.
**Point 2 (15 to 27s):** Check auth and validate input on the server, always. Never trust what the client or the agent sends.
**Point 3 (27 to 38s):** Log requests so you can search them, and alert on odd spikes. You cannot fix what you cannot see.
**CTA (38 to 45s):** "I built a free path that teaches web developers to build and protect AI apps. Link in bio: https://ai-academy-mauve-five.vercel.app/ai-engineer-roadmap". For a carousel, one point per slide and the link on the last.
