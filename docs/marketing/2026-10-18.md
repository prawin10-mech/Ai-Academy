## a. Today's angle
Model prices and choices changed again this week, so "which model" is not a choice you make once. According to a weekly roundup (SeeThrough AI, Oct 11 to 17), Google's Gemini 4 Argon API is paid only at $2 per million input tokens and $10 per million output, and it reports the price rises to $4 and $20 on Dec 1 (that figure is Simon Willison's, relayed by the roundup, so I did not check it at the source). Reflection also announced an open-weights coding model, Beam, on Oct 5; it says weights come later in October, and its benchmark numbers are its own and not independently checked. For web developers the lesson is old and familiar: do not hard-code a vendor. Put the model behind one function, and keep a small test set so you can swap and compare. Different from earlier packs (evals, bots hitting APIs, agent hosting cost): today is about staying portable.

Sources: [SeeThrough AI, week 33](https://seethroughai.substack.com/p/top-ai-news-of-the-week-33-october), [Reflection Beam, Let's Data Science, Oct 6](https://letsdatascience.com/news/reflection-introduces-beam-open-weight-reasoning-model-b6a0e32f), [AI Agents News Brief, Oct 17](https://aiagentsdirectory.com/news/ai-agents-news-brief-october-17-2026). I do not know which model will win. You do not need to. Web developers already know the fix, because we never hard-code one payment provider or one database driver:

2. Keep 20 real tasks with known good answers.
3. Run them on each new model and compare quality and cost per task.
4. Switch only when the numbers say so.
