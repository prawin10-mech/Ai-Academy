Your AI agent is only as safe as its tool list.

On Oct 15, a startup called Opsin announced a $21M round to help companies see what their AI agents can access and do. The reason, as reported: agents are moving from answering questions to taking actions across company systems.

Web developers already know this problem. We never give an API key more rights than it needs. An agent deserves the same care:

1. Write down every tool it can call, in one list.
2. Give each tool the smallest permission that works (read-only first).
3. Ask for a human OK before anything that sends, pays or deletes.
4. Log every call, so you can answer "what did it do?"
