## a. Today's angle
Open weights are not the same as free for any use. The DEV Community digest reports Mistral announced Large 4 on Oct 29: a 1 trillion parameter model with open weights on Hugging Face, under a modified MIT license. It says you can use, fine-tune and sell products with it, but reselling it as a hosted model service needs a separate commercial license. The same digest reports API prices from $0.70 per million input tokens and $2.10 per million output tokens. Why it matters to web developers: "open" tempts you to build on it fast, but you must read the license, check the hardware, and keep your model easy to swap. Earlier packs covered model swapping on Oct 18, but this angle is about reading the license and the real cost before you commit.

Source: [DEV Community digest, Oct 29](https://dev.to/hiroki-ii-ai/ai-daily-digest-october-30-2026-mistral-opens-a-trillion-parameters-cloud-giants-report-openai-1gk7), [The Neuron, Oct 30](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-october-30-2026/)

Before you build on any "open" model, I would do 4 things:
1. Read the license, not the headline.
2. Price it two ways: the hosted API per million tokens, and the GPUs if you run it yourself.
3. Keep the model name in one config file so you can swap it.
4. Run your own 20 test questions on it before you trust any benchmark.

Benchmarks in launch posts are the maker's own numbers. Your own 20 tasks are the ones that matter.
