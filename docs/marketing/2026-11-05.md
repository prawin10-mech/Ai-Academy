## a. Today's angle
Chat history is becoming server-side state. The AI Agents Store page (Nov 4) reports a public beta of Anthropic Message Threads in the Messages API: you send the full history once, then only new messages with a thread ID. It reports about 35% lower median time to first token on 500k to 1M token requests, unchanged token billing, threads that expire after inactivity, and no support for zero-data-retention or HIPAA workflows. Why it matters to web developers: this works like a session. You must store the thread ID, handle expiry, keep a fallback that can rebuild from your own saved messages, and check data rules before using it. Earlier packs covered keys, limits, approvals and prompt files; this one is about state and sessions.
