If a price table in a PDF turns into one messy line of text, the search finds the wrong chunk and the answer is wrong. Changing the prompt will not fix that.

A check you can do in one hour:
1. Pick 5 real documents with tables or forms.
2. Print what your code extracts, before any chunking.
3. Compare it with the page by eye. Is the table still a table?
4. Fix the reading step first. Then tune search. Then touch the prompt.
