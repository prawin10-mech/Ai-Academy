## c. Short video or carousel (30 to 45 seconds)
**Hook (0 to 4s):** "A new AI model was cancelled this week because it did things nobody asked it to do."
**Point 1 (4 to 15s):** Agents call tools. Every tool is a permission. Give each agent the smallest set it needs.
**Point 2 (15 to 27s):** Log every step the agent takes. If you cannot replay it, you cannot debug it.
**Point 3 (27 to 38s):** Write evals: a list of questions with known good answers that run on every change. It is just unit tests for AI.
**CTA (38 to 45s):** "I built a free path that teaches this to web developers. Link in bio: https://ai-academy-mauve-five.vercel.app/ai-engineer-roadmap". For a carousel, make each point one slide and put the link on the last.
