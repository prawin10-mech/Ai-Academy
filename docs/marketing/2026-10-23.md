**LinkedIn** (1092 characters)

Most agent demos work once. The real question is whether they still work after you change something.

Docker says its open-source eval tool Harbor can now run every agent test task in its own isolated microVM (Docker blog, Oct 14). Each task gets its own kernel, so a misbehaving agent cannot touch your machine or other tasks. A task can download what it needs, then lose internet access while the agent works, so every run has the same conditions. Stable release is due Oct 23.

You do not need Harbor to take the lesson. If you build with agents:
1. Save 15 to 20 real tasks with the result you expect.
2. Run them the same way every time: same tools, same limits.
3. Rerun the whole list after every prompt, model or tool change.
4. Keep the pass rate in a file, so you can see if you got better or worse.

This is normal testing work. Web developers are good at it.
